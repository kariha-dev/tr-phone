All notable changes to TR Phone will be documented in this file.

## [Unreleased]

## [1.0.0] - 2026-09-23

- Initial stable release for Turkish phone number parsing, validation, and normalization.
- E.164, national, international, and compact formatting support.
- Mobile and geographic landline detection.
- Geographic area-code recognition.
- Prefix allocation and prefix service information.
- Exception-based error handling and safe parsing with `tryParse()`.
- Turkish and English documentation.
- PHPUnit tests, PHPStan analysis, and code-style checks.
- GitHub Actions CI.
- PHP 8.1, 8.2, 8.3, and 8.4 support.
