# Security Policy

TR Phone runs locally and does not send phone numbers to Kariha or any third party. There are no external API calls and no database connection.

## Reporting a Vulnerability

Please report security concerns privately by emailing:

`security@kariha.net`

Include a clear description, affected version or commit, reproduction steps, and any relevant impact. Please do not include real customer phone numbers unless absolutely necessary; mask personal data where possible.

Additional security disclosure information:

- https://www.kariha.net/.well-known/security.txt
- https://www.kariha.net/guvenlik-bildirimi.html
- https://www.kariha.net/en/security-disclosure.html

We do not claim any formal security certification for this package.
